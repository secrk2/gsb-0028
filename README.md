# 织云系统 · 应用台账与资产控制台

面向多团队的应用资产管理系统：**应用台账**（全生命周期登记）+ **资产控制台**（分布、变更、风险红点）+ **配置档案**（按应用×环境管理配置项、密文管控、环境对比、版本回滚）+ **变更留痕**（配置逐键流水、时间窗查询、差异清单导出）。

## 一键启动

```bash
docker compose up -d --build
```

访问 http://localhost:8016 。首次启动自动建库并写入初始数据（4 条业务线、9 个账号、24 个应用，覆盖 在研/上线/维保/下线 全部状态，含缺负责人 / 缺环境变量的红点样例）。

本地开发（不用 Docker）：

```bash
pip install -r requirements.txt
uvicorn app.main:app --port 8016
```

## 功能与规则

- **应用台账**：应用挂所属业务线、负责人、集群、环境（开发/测试/预发/生产）、生命周期状态；列表支持业务线 + 负责人 + 环境 + 状态 + 关键字组合筛选。
- **生命周期状态机**：`在研 → 上线 → 维保 → 下线`，只能向前流转；**下线为终态**，状态与所有信息（含环境变量）只读。状态回退（如 维保→上线）会被拦截并返回具体原因。
- **唯一性**：同一业务线下应用名不能重复（创建/改名均校验，返回 409 及原因）。
- **资产控制台**：各业务线应用数分布（按状态分段）、近 7 天有变更的应用、环境变量缺失 / 缺失负责人的红点提醒。
- **越权防护**：普通成员仅能访问本业务线数据；访问其他业务线的应用或按其他业务线筛选返回 **403 错误态页面**（非空白页）。
- **变更留痕**：创建、信息变更、状态流转、环境变量修改均写入变更日志。

### 配置档案

配置项按 **应用 + 环境**（开发/测试/预发/生产）管理，每个配置项包含：键、值、类型（字符串/数字/布尔/JSON，服务端强校验）、生效范围（全局/集群/灰度）、是否密文。

- **密文管控（服务端强制）**：密文在档案、环境对比、版本快照、留痕、CSV 导出中**一律脱敏**（`••••••••`），明文不随列表下发；查看明文只能调 reveal 接口，必须填写不少于 5 个字的业务理由，**理由为空/过短由服务端拒绝（400），仅在前端拦截不算数**；每次查看逐条写留痕（谁、何时、看了哪个键、什么理由）。
- **环境对比**：任选两个环境一键 diff，按「值不同 / 仅左环境有 / 仅右环境有 / 一致」分类着色，开发与生产差了哪些键一眼可见；密文差异只提示不同、不泄露明文。
- **版本与回滚**：每次保存生成全量快照版本（无变化不产生空版本），可查看任意历史快照；回滚到旧版 = **追加一个新版本**，旧版本与所有历史留痕原样保留、绝不被覆盖；回滚本身按逐键 add/remove/update 留痕，动作记为「回滚」并注明目标版本。
- **只读约束**：应用下线（终态）后，配置档案不能编辑、不能回滚。

### 变更留痕

- 配置的**每次**改动（新增/修改/删除/回滚/查看明文）都有逐键流水：应用、环境、配置键、改前值、改后值（密文脱敏）、操作人、时间、理由/备注。
- 支持按 **应用 / 业务线 / 环境 / 动作 / 起止日期** 组合查询（成员强制限定本业务线，越权 403）。
- 一键**导出差异清单 CSV**（带 UTF-8 BOM，Excel 直接打开不乱码；密文列同样脱敏）。

## 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/login` | 登录（`{"username": "zhangwei"}`） |
| GET | `/api/apps` | 台账列表，参数：`business_line_id` `owner_id` `environment` `status` `q` |
| POST | `/api/apps` | 新建应用（同业务线重名 → 409） |
| GET | `/api/apps/{id}` | 详情（越权 → 403） |
| PATCH | `/api/apps/{id}` | 修改信息（已下线 → 400） |
| POST | `/api/apps/{id}/status` | 状态流转（回退/终态 → 400 及原因） |
| PUT | `/api/apps/{id}/env-vars` | 整体替换环境变量 |
| GET | `/api/console/summary` | 控制台汇总（分布/近 7 天变更/红点） |
| GET | `/api/config/profiles` | 配置档案列表（应用×环境，支持业务线/环境筛选） |
| GET | `/api/apps/{id}/config?environment=` | 某应用某环境的配置项 + 版本历史（密文脱敏） |
| PUT | `/api/apps/{id}/config?environment=` | 整体保存，产生一个新版本（类型校验/重复键/无变化 → 400） |
| POST | `/api/apps/{id}/config/reveal` | 查看密文明文（**服务端强制理由 ≥5 字，留痕**；缺理由 → 400） |
| GET | `/api/apps/{id}/config/diff` | 环境对比，参数：`env_a` `env_b` |
| GET | `/api/apps/{id}/config/versions?environment=` | 版本列表 |
| GET | `/api/apps/{id}/config/versions/{n}?environment=` | 某版本快照（密文脱敏） |
| GET | `/api/apps/{id}/config/rollback-preview?environment=&version=` | 回滚前预览当前→目标版本差异 |
| POST | `/api/apps/{id}/config/rollback` | 回滚（**追加新版本，不覆盖历史留痕**） |
| GET | `/api/config/audit` | 配置留痕查询，参数：`app_id` `business_line_id` `environment` `action` `start` `end` |
| GET | `/api/config/audit/export.csv` | 导出差异清单 CSV（同样的筛选参数，密文脱敏） |

认证：请求头 `X-Token: <登录返回的 token>`。

## 目录结构

```
app/
  main.py            # FastAPI 入口与台账/控制台路由
  auth.py            # 鉴权、业务线数据范围、应用取数公共依赖
  config_service.py  # 配置领域服务：类型校验/快照版本/diff/回滚/审计查询/CSV
  routers/config.py  # 配置档案 & 变更留痕 API
  db.py              # SQLite 连接与表结构、状态机/配置常量
  seed.py            # 初始数据（含多版本配置档案、密文、查看明文留痕样例）
  static/            # 前端（原生 JS，无构建步骤）
docker-compose.yml
Dockerfile
```
